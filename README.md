# Just One More Game Studio — Retro Revival website

Static GitHub Pages site for justonemoregamestudio.co.uk.

## Structure
- `index.html` — studio / Retro Revival homepage
- `games/bombing-buildings.html` — Bombing Buildings game page
- `privacy-policy.html` — privacy policy for Bombing Buildings
- `styles.css` — shared styling
- `script.js` — small mobile navigation script
- `CNAME` — custom GitHub Pages domain
- `assets/` — website artwork

## GitHub Pages
Create a public GitHub repository, upload these files, then enable Pages from the repository's Settings. The included `CNAME` file is for `justonemoregamestudio.co.uk`.

Before publishing, verify the privacy policy against the final app build and Play Console Data safety answers.
